# Combat Shooter Game

## Description
"Combat Shooter" is a first-person shooter game developed using Unity. In this game, players navigate through environment, shoot enemies, and aim to complete objectives.

## Features
- **Third-person shooter gameplay**: Players experience the action from a third-person perspective.
- **Shooting mechanics**: Players can shoot enemies.
- **Enemy AI**: The game features intelligent enemy AI that provides a challenging experience.
- **player controls**: Use mouse and keyboard to move and aim.
- **Health system**: Players must manage their health and survive against enemy forces.
- **Developed with Unity**: Created using the Unity game engine for cross-platform compatibility.
